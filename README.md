# create-tletelieru-app

Scaffolds a React + TypeScript PWA, on Vite or Astro, ready for GitHub Pages.

```sh
node bin/create.mjs my-app --title "My App" --description "What it does" --port 5190 --framework astro --no-mui --locales es
```

Missing values are asked for in a terminal. Includes light/dark, a generated icon set, ESLint + Prettier, Husky + lint-staged, Vitest + Testing Library, and a workflow that runs lint and tests on PRs and deploys to Pages only from `main`.

| Option | Values | Default |
| --- | --- | --- |
| `--framework` | `vite`, `astro` | `vite` |
| `--mui`, `--no-mui` | MUI or plain CSS | MUI |
| `--locales` | `en`, `es`, `en,es` | `en,es` |
| `--no-install` | Skip `pnpm install` and icon generation | |

A ready-to-use Vite + MUI app generated by this CLI lives in [tletelieru-app-template](https://github.com/tletelieru/tletelieru-app-template), for "Use this template".

## Development

`templates/base` is copied first, then `vite` or `astro`, then `no-mui` when MUI is off. Each framework has a `package.fragment.json` merged into `package.json`. Lines between `// @if flag` and `// @endif` (or the HTML comment form) stay only when the flag is on: `en`, `es`, `both`, `mui`, `nomui`. `.gitignore` is stored as `_gitignore` because npm drops it from packages.

```sh
pnpm test
```
